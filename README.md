# git-practice
Practice repository for team Git and GitHub practice

This repository is used to practice Git and Github workflows.

## Git Workflow

1. Create a branch
2. Make changes
3. Commit changes
4. Push the branch
5. Create a pull request
6. Review the changes
7. Merge into main
8. Switch to main and pull the latest changes

## Branch Rules

- Do not edit main directly.
- Use one branch for each task.
- After merging, switch to main and pull the latest changes.
